Contact

Questions, bug reports, accessibility issues and privacy requests

Email

The site is completely static, so there is no contact form — anything typed into a form would have nowhere to go. Email is the reliable route:

contact@argenrise.com

Best-effort replies. MechKit is a free project, so please allow a little patience.

Reporting a wrong result

Calculation bugs are the most useful reports. Please include:

  • the tool name, as shown in the sidebar;
  • the inputs you used, with units;
  • the result the site gave you;
  • the result you expected, and where it comes from — a formula, textbook, standard or hand calculation;
  • your browser and operating system.

Please don't send confidential drawings, client data or export-controlled material. A screenshot of the inputs and results is usually enough.

Problems with a custom source

If a JSON or CSV source you added fails to load, attach the file (or paste the first few lines) together with the message shown. That is usually enough to find the problem. The Manage sources page lists the format and includes examples.

Accessibility and privacy

Accessibility barriers and privacy questions go to the same address. For privacy, please mention which part of the site you are asking about — much of what the site stores lives only in your own browser, and the privacy policy explains how to clear it. If you are reporting an accessibility problem, see the accessibility statement for the details that help most.
